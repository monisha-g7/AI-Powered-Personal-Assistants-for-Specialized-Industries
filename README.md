# 🧠 AI-Powered Industry-Specific Personal Assistant

## Description
This Flask-based AI assistant provides domain-specific support for industries such as **healthcare** and **legal services**. Users can interact through **voice** or **text** to receive **AI-generated, context-aware responses**. The assistant is enhanced with text-to-speech functionality and a simple web interface.

## Features
- 🎤 Voice and text input (via Flask)
- 🧠 Domain-specific prompt engineering (Healthcare & Legal)
- 🔁 AI-powered response generation using OpenAI
- 🔊 Text-to-speech (pyttsx3)
- 🌐 Frontend UI (HTML/CSS/JS)
- 📁 Upload audio files for transcription and answer

## Setup
```bash
pip install -r requirements.txt
python ai_industry_assistant.py
```
